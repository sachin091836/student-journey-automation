Student Journey Autopilot

Today the same student lives in six tools and a person copies them between each one. Leads get dropped and access gets granted late. One n8n workflow now carries every handoff, and a separate alert workflow speaks up the moment any step fails.

Error layer: nothing fails silently separate workflow · Error Trigger + daily schedule

Retry 3× on every API call3 seconds apart, which absorbs rate limits and brief outages without anyone noticing.
Slack + email alertNames the tool, the failing step and the API error, with a link to the exact run.
Safe one-click retryEvery write is an upsert or deduplicated (Klaviyo unique_id), so rerunning never double-sends.
